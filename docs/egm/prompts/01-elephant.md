# Phase 1 — Elephant: master specification

Prerequisites: approved Phase 0 inventory and owner product decisions.

Produce `docs/egm/01-master-spec.md` with product scope, existing-feature preservation, personas, user journeys, functional requirements with stable IDs, nonfunctional requirements, UI states, API contracts, persistence, migration, privacy/security, analytics, accessibility, testable acceptance criteria, rollout and rollback.

Include fasting only as a proposed feature until the owner approves it. Define start, stop, cancel, overlapping-session rules, timezone/clock changes, history, offline sync and clearly qualified phase explanations. Avoid precise metabolic or medical claims unsupported by evidence.

Separate verified as-is behavior, proposed to-be behavior and open decisions. Do not modify product code.
