# Phase 3 — Implementation planner and coding agents

Prerequisite: explicit owner approval of the versioned master specification and resolved Goldfish blockers.

Create `docs/egm/03-implementation-plan.md` with small, independently testable tasks. Each task must link requirement IDs, affected files, dependencies, acceptance tests, risks and rollback.

Coding agents work on separate branches and open PRs; no direct pushes to `master`, no auto-merge, no production deployment. Run relevant tests, lint and build, documenting results and limitations. Keep health-data authorization, privacy and existing mobile functionality intact.
